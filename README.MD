# Система управления личными интересами (Interest Tracker)

## Назначение
Приложение предназначено для структурирования, учёта и отслеживания личных интересов, хобби и направлений саморазвития пользователя. Система помогает планировать время на увлечения, ставить цели по обучению или практике, а также контролировать регулярность занятий.

## Целевая аудитория
Люди, стремящиеся осознанно управлять своим свободным временем, студенты, специалисты в процессе самообразования и смены квалификации, а также все, кто хочет гармонично совмещать несколько разнородных увлечений (спорт, творчество, профессиональное развитие, чтение).

## Предметная область
Личная продуктивность, тайм-менеджмент и организация свободного времени. Предметная область охватывает процессы формирования каталога интересов, распределения их по направлениям жизни, фиксации прогресса и затраченного времени, а также оценки вовлечённости пользователя.

## Основные сущности
1. **Пользователь (`User`)** — владелец профиля, управляющий своим набором интересов и личными целями.
2. **Сфера / Категория (`Category`)** — тематическая область увлечений (например, «Программирование», «Спорт», «Языки», «Творчество»).
3. **Интерес / Хобби (`Interest`)** — конкретное направление деятельности с описанием, текущим статусом, приоритетом и целевыми метриками.
4. **Запись активности (`ActivityLog`)** — отметка о занятии увлечением с указанием затраченного времени, даты и заметок о результате.
5. **Цель (`Goal`)** — целевой ориентир по интересу (например, уделять не менее 8 часов в неделю или прочитать 10 глав).

## Основные функции
1. **Каталогизация и учёт параметров увлечений:** хранение и представление структурированной информации об интересе (наименование, тематическая категория, дата фиксации и признак активности).
2. **Валидация и расчёт прогресса по целям:** преобразование строковых входных данных о затраченном времени в числовой формат и вычисление процента выполнения установленного недельного норматива часов с математическим округлением.
3. **Анализ вовлечённости и генерация рекомендаций:** многофакторная оценка состояния увлечения через условные ветвления (проверка нахождения в архиве, превышения плана или дефицита времени) с автоматическим расчётом остатка необходимых часов и формированием обратной связи пользователю.

## План развития
На следующих этапах реализации планируется:
- Разработка веб-приложения на базе фреймворка Django;
- Проектирование реляционной схемы и подключение базы данных (PostgreSQL / SQLite);
- Реализация системы аутентификации, регистрации и разграничения прав доступа пользователей;
- Разработка REST API для интеграции с мобильными или внешними клиентами;
- Покрытие ключевой бизнес-логики автоматизированными тестами (pytest);
- Контейнеризация приложения с использованием Docker и Docker Compose;
- Настройка базового CI/CD пайплайна для автоматической проверки и развёртывания.
