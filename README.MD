# Система управления личными интересами (Interest Tracker)

Консольное приложение для учёта личных интересов и хобби, затраченного на них времени и недельных целей.

## Назначение
Приложение предназначено для структурирования, учёта и отслеживания личных интересов, хобби и направлений саморазвития пользователя. Система помогает планировать время на увлечения, ставить цели по обучению или практике, а также контролировать регулярность занятий.

## Целевая аудитория
Люди, стремящиеся осознанно управлять своим свободным временем, студенты, специалисты в процессе самообразования и смены квалификации, а также все, кто хочет гармонично совмещать несколько разнородных увлечений (спорт, творчество, профессиональное развитие, чтение).

## Предметная область
Личная продуктивность, тайм-менеджмент и организация свободного времени. Предметная область охватывает процессы формирования каталога интересов, распределения их по направлениям жизни, фиксации прогресса и затраченного времени, а также оценки вовлечённости пользователя.

## Основные сущности
1. **Пользователь (`User`)** — владелец профиля, управляющий своим набором интересов и личными целями.
2. **Сфера / Категория (`Category`)** — тематическая область увлечений (например, «Программирование», «Спорт», «Языки», «Творчество»).
3. **Интерес / Хобби (`Interest`)** — конкретное направление деятельности с описанием, текущим статусом, приоритетом и целевыми метриками.
4. **Запись активности (`ActivityLog`)** — отметка о занятии увлечением с указанием затраченного времени, даты и заметок о результате.
5. **Цель (`Goal`)** — целевой ориентир по интересу (например, уделять не менее 8 часов в неделю или прочитать 10 глав).

На этапе ПР2 классы не используются: интерес и запись активности представлены словарями, категория — полем интереса, недельная цель — полем `weekly_goal`. Пользователь в программе пока не реализован, объектная модель будет введена в ПР3.

## Основные функции
Функции начального сценария ПР1 сохранены и теперь работают с данными из коллекций:
1. **Каталогизация и учёт параметров увлечений** — `display_interest_card()` (`main.py`) выводит карточку интереса;
2. **Расчёт прогресса по целям** — `calculate_progress()` (`activities.py`) считает процент выполнения недельной цели;
3. **Анализ вовлечённости и рекомендации** — `generate_recommendation()` (`activities.py`) формирует совет с учётом статуса интереса (активен или в архиве), процента выполнения цели и остатка часов.

## Возможности
- просмотр интересов, поиск по названию, сортировка по недельной цели;
- добавление интересов;
- учёт активности: добавление и отмена записей о занятиях (дата и часы);
- проверка доступности: запись активности возможна только для существующего интереса, который не находится в архиве;
- прогресс интереса за неделю: карточка и рекомендация;
- статистика: часы по каждому интересу и общий итог;
- данные хранятся в JSON-файлах: загружаются при запуске и сохраняются после каждого изменения;
- некорректный ввод и ошибки при работе с файлами не приводят к аварийному завершению программы.

Неделя определяется по календарю (понедельник — воскресенье). Недельная цель — от 0 до 168 часов, время одного занятия — от 0 до 24 часов.

## Структура проекта
```
personal_interesting/
├── README.MD
├── requirements.txt
├── pytest.ini
├── .flake8
├── main.py
├── interests.py
├── activities.py
├── storage.py
├── utils.py
├── data/
│   ├── interests.json
│   └── activities.json
└── tests/
    ├── test_interests.py
    ├── test_activities.py
    └── test_storage.py
```

- `main.py` — точка запуска, меню и функции вывода данных;
- `interests.py` — работа с интересами: добавление, поиск, сортировка, проверка активности;
- `activities.py` — записи активности, расчёт прогресса, рекомендации, статистика;
- `storage.py` — сохранение и загрузка данных в JSON;
- `utils.py` — безопасный ввод данных и вспомогательные функции;
- `data/` — JSON-файлы с данными (подготовленные данные для проверки работы);
- `tests/` — автоматизированные тесты pytest;
- `pytest.ini` и `.flake8` — настройки запуска тестов и линтера.

## Формат данных
Данные хранятся в каталоге `data/`. Каждый файл — список словарей, даты записаны строкой `ГГГГ-ММ-ДД`. В программе интересы хранятся в словаре `{номер: интерес}`, записи активности — в списке. Если файла нет, программа начинает с пустых данных; если файл повреждён, выводится сообщение и данные из него не загружаются.

`data/interests.json`:
```json
[
    {
        "id": 1,
        "name": "Изучение веб-разработки на Python",
        "category": "Программирование",
        "created_date": "2026-09-08",
        "is_active": true,
        "weekly_goal": 8.0
    }
]
```

`data/activities.json`:
```json
[
    {
        "id": 1,
        "interest_id": 1,
        "activity_date": "2026-09-08",
        "hours": 2.0
    }
]
```

## Требования
- Python 3.10 или новее;
- pytest;
- flake8.

Основной код использует только стандартную библиотеку. Установка инструментов разработки:
```
pip install -r requirements.txt
```

## Запуск программы
```
python main.py
```

Меню программы:
```
=== Система управления личными интересами ===
1. Показать интересы
2. Найти интерес по названию
3. Отсортировать интересы по недельной цели
4. Добавить интерес
5. Записать активность
6. Отменить запись активности
7. Показать записи активности
8. Прогресс интереса за неделю
9. Статистика
0. Выход
```

В каталоге `data/` лежат подготовленные данные: 5 интересов и 12 записей активности за две недели (07.09–13.09.2026 и 14.09–20.09.2026). Даты вводятся в формате `ДД.ММ.ГГГГ`. Чтобы посмотреть прогресс на подготовленных данных, в пункте 8 введите номер интереса и любую дату недели 14.09–20.09.2026, например `16.09.2026`.

Пример вывода пункта 8 (интерес 1, дата 16.09.2026):
```
=======================================================
КАРТОЧКА ИНТЕРЕСА: ИЗУЧЕНИЕ ВЕБ-РАЗРАБОТКИ НА PYTHON
=======================================================
Категория:          Программирование
Дата добавления:    08.09.2026
Статус активности:  Активен
План на неделю:     8.0 ч.
Затрачено:          9.0 ч.
Прогресс:           112.5%
-------------------------------------------------------
Рекомендация:       Отличный результат! Недельная цель полностью выполнена.
=======================================================
```

## План развития
На следующих этапах реализации планируется:
- Переход к объектной модели: классы `User`, `Category`, `Interest`, `ActivityLog`, `Goal` (ПР3);
- Разработка веб-приложения на базе фреймворка Django;
- Проектирование реляционной схемы и подключение базы данных (PostgreSQL / SQLite);
- Реализация системы аутентификации, регистрации и разграничения прав доступа пользователей;
- Разработка REST API для интеграции с мобильными или внешними клиентами;
- Расширение покрытия ключевой бизнес-логики автоматизированными тестами (pytest);
- Контейнеризация приложения с использованием Docker и Docker Compose;
- Настройка базового CI/CD пайплайна для автоматической проверки и развёртывания.
